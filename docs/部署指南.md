# 校园课程互助答疑系统 —— 部署指南

## 一、环境要求

| 软件 | 版本 | 说明 |
|---|---|---|
| JDK | 17+ | Spring Boot 3 最低要求 JDK 17，JDK 8 无法运行 |
| Maven | 3.8+ | 用于拉取依赖、启动后端；也可用 IDEA 内置 Maven |
| Node.js | 18+ | 前端构建 |
| MySQL | 8.x | 数据库 |

## 二、初始化数据库（只需执行一次）

在项目根目录执行（把路径换成你自己的项目路径）：

```bash
mysql -uroot -p123456 --default-character-set=utf8mb4 -e "source ./docs/init.sql"
```

或在 Navicat / MySQL Workbench 里直接打开 `docs/init.sql` 全选执行。

脚本会自动完成：

- 创建数据库 `course_qa_db`（utf8mb4）
- 创建 6 张表：`user`、`course`、`post`、`reply`、`post_like`、`favorite`
- 插入预置账号与示例答疑数据

> 数据库连接账号密码写在 `backend/src/main/resources/application.yml`，默认 `root/123456`，与本机不一致时请先修改该文件。

## 三、启动后端（端口 8080）

**方式一：命令行**

```bash
cd backend
mvn spring-boot:run
```

**方式二：IDEA**

用 IDEA 打开 `backend` 目录（识别 `pom.xml` 为 Maven 项目），等待依赖下载完成，运行 `QaApplication` 主类。

控制台出现 `Started QaApplication` 即启动成功。首次启动会自动创建图片上传目录 `backend/upload/`。

## 四、启动前端（端口 5173）

新开一个终端：

```bash
cd frontend
npm install     # 首次运行执行一次
npm run dev
```

浏览器访问 **http://localhost:5173**

> 前端通过 Vite 代理把 `/api`、`/files` 转发到 `http://localhost:8080`，配置见 `frontend/vite.config.js`，无需额外处理跨域。

## 七、常见问题

| 问题 | 处理 |
|---|---|
| 前端提示"网络异常" | 后端 8080 未启动，先启动后端 |
| 后端启动报数据库连接失败 | 确认 MySQL 服务已启动、`application.yml` 账号密码正确、`course_qa_db` 已创建 |
| 启动报 `Unsupported class file major version` | JDK 版本低于 17，换 JDK 17 后在 IDEA 中重新配置 SDK |
| 登录提示 token 失效 | 后端重启会清空内存中的 token（课设简化实现，未引入 Redis），重新登录即可 |
| 端口被占用 | 8080/5173 被占用时，`netstat -ano \| findstr :8080` 找到 PID 后 `taskkill /pid <PID> /f` |
| 图片不显示 | 上传文件保存在后端运行目录的 `upload/`，该目录被删除后图片自然失效 |

## 八、项目结构

```
course-qa-system/
├── backend/                          Spring Boot 3.2.5 + MyBatis-Plus
│   ├── pom.xml
│   └── src/main/java/com/campus/qa/
│       ├── common/                   Result 统一返回、全局异常、Token、用户上下文
│       ├── config/                   MyBatis-Plus 分页插件、Web 拦截器与静态资源映射
│       ├── interceptor/              登录校验 + 管理员权限校验
│       ├── controller/               7 个控制器，只做参数接收与结果封装
│       ├── service/ + impl/          业务逻辑层（接口 + 实现）
│       ├── entity/                   6 张表对应实体
│       └── mapper/                   MyBatis-Plus Mapper 与统计 SQL
├── frontend/                         Vue3 + Vite + Element Plus + ECharts + Pinia
│   └── src/{api,router,stores,views}
└── docs/                             建库脚本、接口文档、本说明、课设辅助材料
```
