## 六、功能验收清单

**学生端（成员1）**
- [ ] 注册新学号 → 登录
- [ ] 首页按课程标签筛选、关键词搜索答疑帖
- [ ] 发布问题（选课程分类、填标题内容、上传配图）
- [ ] 帖子详情：发表回复、点赞/取消点赞（重复点赞自动切换）、收藏
- [ ] 个人中心：我的提问 / 我的回复 / 我的收藏 三个Tab；编辑昵称与头像

**管理员端（成员2）**
- [ ] admin 登录 → 自动进入管理后台
- [ ] 课程分类管理：新增（如"大学物理"）/编辑/删除（有帖子的课程会拒绝删除）
- [ ] 帖子审核：查看内容 → 屏蔽/恢复发布/删除（屏蔽后前台不可见）
- [ ] 用户管理：禁言（该用户无法发帖回复）、封禁（无法登录）、重置密码
- [ ] 数据统计：课程提问量柱状图、近7日趋势折线图、点赞TOP10、活跃用户TOP10

## 七、常见问题

| 问题 | 处理 |
|---|---|
| 前端报"网络异常" | 后端 8080 未启动，先启动后端 |
| 后端启动报数据库连接失败 | 确认 MySQL80 服务已启动、密码正确 |
| 登录提示 token 失效 | 后端重启会清空内存 token，重新登录即可（课设简化实现） |
| 端口被占用 | 8080/5173 被占时，用 `netstat -ano | findstr :8080` 找到 PID 后 `taskkill /pid <PID> /f` |
| 图片不显示 | 上传目录在 backend 运行目录下的 `upload/`，删除后图片丢失属正常 |

## 八、项目结构

```

├── sql/course_qa_db.sql          # 建库建表+预置数据
├── backend/                      # Spring Boot 3.2.5 + MyBatis-Plus
│   ├── pom.xml
│   └── src/main/java/com/campus/qa/
│       ├── common/               # Result统一返回、全局异常、Token、用户上下文
│       ├── config/               # MyBatis-Plus分页、Web拦截器与静态资源
│       ├── interceptor/          # 登录+管理员权限拦截器
│       ├── entity/               # 6张表实体
│       ├── mapper/               # MyBatis-Plus Mapper + 统计SQL
│       └── controller/           # Auth/Post/Interaction/Course/File/Admin/Stats
├── frontend/                     # Vue3 + Vite + Element Plus + ECharts + Pinia
│   └── src/{api,router,stores,views}
└── docs/                         # 接口文档、本说明
```
