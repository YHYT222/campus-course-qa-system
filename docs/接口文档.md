# 校园课程互助答疑系统 —— 接口文档

> 基础地址：`http://localhost:8080`
> 除标注"无需登录"的接口外，均需在请求头携带 `token: <登录返回的token>`。
> 统一响应格式：`{ "code": 200, "msg": "操作成功", "data": ... }`
> code 含义：`200` 成功｜`401` 未登录/token失效｜`403` 无管理员权限｜`500` 业务错误

---

## 一、认证模块 /api/auth

| 接口 | 方法 | 说明 | 请求参数 |
|---|---|---|---|
| /api/auth/register | POST | 学号注册（无需登录） | `{ "studentNo": "20230010", "username": "昵称", "password": "123456" }` |
| /api/auth/login | POST | 登录（无需登录） | `{ "studentNo": "20230001", "password": "123456" }` |
| /api/auth/me | GET | 当前用户信息 | — |
| /api/auth/profile | PUT | 编辑昵称/头像 | `{ "username": "新昵称", "avatar": "/files/xxx.png" }` |

**登录成功响应**：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "token": "a3f5c8...",
    "user": { "id": 2, "studentNo": "20230001", "username": "张同学",
              "role": 0, "avatar": null, "status": 0, "createTime": "2026-11-07T10:00:00" }
  }
}
```

## 二、课程分类 /api/course

| 接口 | 方法 | 说明 |
|---|---|---|
| /api/course/list | GET | 全部课程分类（无需登录） |

## 三、图片上传 /api/file

| 接口 | 方法 | 说明 |
|---|---|---|
| /api/file/upload | POST | multipart 表单，字段名 `file`，仅 png/jpg/jpeg/gif/webp，≤10MB；返回 `{ "url": "/files/xxx.png" }` |

## 四、答疑帖子 /api/post

| 接口 | 方法 | 说明 | 参数 |
|---|---|---|---|
| /api/post/page | GET | 分页浏览已发布帖 | `page`、`size`、`courseId`(可选)、`keyword`(可选) |
| /api/post/{id} | GET | 帖子详情（含回复列表、当前用户点赞/收藏状态、isOwner/isAdmin） | — |
| /api/post | POST | 发布答疑帖 | `{ "courseId": 1, "title": "标题", "content": "内容", "image": "/files/x.png"(可选) }` |
| /api/post/my | GET | 我的提问（含各状态） | — |
| /api/post/{id} | DELETE | 删除自己的帖子（管理员可删任意帖） | — |

**帖子详情响应（节选）**：

```json
{
  "code": 200,
  "data": {
    "id": 1, "title": "求极限…", "content": "…", "image": null,
    "likeCount": 3, "status": 1, "courseName": "高等数学",
    "authorName": "张同学", "authorAvatar": null, "createTime": "2026-11-07T10:00:00",
    "isOwner": true, "liked": true, "favorited": false, "isAdmin": false,
    "replies": [
      { "id": 1, "authorName": "李学长", "content": "等价无穷小只能用在乘除因子里…",
        "createTime": "2026-11-07T10:30:00" }
    ]
  }
}
```

## 五、互动 /api/interact

| 接口 | 方法 | 说明 |
|---|---|---|
| /api/interact/like/{postId} | POST | 点赞/取消点赞（切换），返回 `{ "liked": true, "likeCount": 4 }` |
| /api/interact/favorite/{postId} | POST | 收藏/取消收藏（切换），返回 `{ "favorited": true }` |
| /api/interact/favorites | GET | 我的收藏列表 |
| /api/interact/reply | POST | 发表回复 `{ "postId": 1, "content": "回复内容" }` |
| /api/interact/replies/{postId} | GET | 某帖回复列表（按时间正序） |
| /api/interact/my-replies | GET | 我的回复（带帖子标题） |

## 六、管理员端 /api/admin（需管理员角色）

| 接口 | 方法 | 说明 |
|---|---|---|
| /api/admin/course | POST | 新增课程 `{ "name": "大学物理", "description": "..." }` |
| /api/admin/course | PUT | 修改课程 `{ "id": 7, "name": "...", "description": "..." }` |
| /api/admin/course/{id} | DELETE | 删除课程（课程下有帖子时报错拒绝） |
| /api/admin/post/page | GET | 帖子分页：`page`、`size`、`status`(0/1/2，可选)、`keyword`(可选) |
| /api/admin/post/{id}/status/{status} | PUT | 审核：0待审核 / 1通过发布 / 2屏蔽 |
| /api/admin/post/{id} | DELETE | 删除帖子（级联删除回复、点赞、收藏） |
| /api/admin/user/page | GET | 用户分页：`page`、`size`、`keyword`(用户名/学号模糊) |
| /api/admin/user/{id}/status/{status} | PUT | 用户状态：0正常 / 1禁言 / 2封禁（管理员账号不可操作） |
| /api/admin/user/{id}/reset-password | PUT | 重置该用户密码为 `123456` |

## 七、数据统计 /api/stats（需管理员角色）

| 接口 | 方法 | 说明 |
|---|---|---|
| /api/stats/course | GET | 各课程提问量：`[{ "name": "高等数学", "value": 1 }]` |
| /api/stats/trend | GET | 近7日趋势：`{ "dates": ["11-01",…], "posts": [..], "replies": [..] }` |
| /api/stats/top-likes | GET | 点赞TOP10帖：`[{ "id", "title", "likeCount", "courseName" }]` |
| /api/stats/active-users | GET | 活跃用户TOP10：`[{ "name": "李学长", "value": 2 }]` |

## 八、状态字典

| 字段 | 取值 |
|---|---|
| user.role | 0 学生，1 管理员 |
| user.status | 0 正常，1 禁言（不能发帖/回复），2 封禁（不能登录） |
| post.status | 0 待审核，1 已发布，2 已屏蔽 |
