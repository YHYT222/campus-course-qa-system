# 校园课程互助答疑系统

软件工程课程设计 —— 面向高校课程的问答互助平台

## 项目简介

本系统面向在校学生，提供按课程组织的问答互助功能。学生可针对具体课程发布疑问，
其他同学跟帖解答，逐步沉淀为课程维度的知识库，解决课后答疑渠道分散、问题重复提问的问题。

系统采用前后端分离架构，包含学生端与管理员端两套完整业务：学生可注册登录、发布课业问题、
评论回复、点赞收藏、在个人中心管理自己的提问与回复；管理员负责课程分类维护、帖子内容审核、
用户管控以及平台运营数据的可视化统计。

## 功能规划

- [ ] 用户注册与登录（学号注册、账号登录、个人信息编辑、头像修改）
- [ ] 课程分类管理与分类筛选浏览
- [ ] 发布问题（选择课程分类 + 文字描述 + 上传问题截图）
- [ ] 回答问题（帖子评论、回复他人评论）
- [ ] 问题搜索（关键词模糊搜索）与分类筛选
- [ ] 点赞 / 取消点赞、收藏 / 取消收藏
- [ ] 个人中心（我的提问、我的回复、我的收藏、资料修改）
- [ ] 帖子审核机制（提交后待审核，管理员通过后才公开可见）
- [ ] 管理员：课程分类管理、帖子审核、评论管理、用户管理
- [ ] 数据可视化统计（各课程提问量柱状图、平台活跃度折线图）
- [ ] 最佳答案采纳 —— 需求文档未定义该功能，本期未实现

## 技术栈

- 前端：Vue 3.4 + Vite 5.2 + Element Plus 2.6 + ECharts 5.5 + Axios + Vue Router 4
- 后端：Spring Boot 2.7.18 + MyBatis 2.3.1（标准 MVC 分层：Controller / Service / Mapper / Entity）
- 数据库：MySQL 8.0
- 运行环境：JDK 1.8+ 、Node.js 16+、Windows / macOS

## 运行方式

### 1. 初始化数据库

用 MySQL 8.0 执行 `docs/init.sql`，脚本会自动建库 `course_qa`、建表并插入管理员与示例数据。

### 2. 启动后端

修改 `backend/src/main/resources/application.yml` 中第 9-10 行的 MySQL 用户名和密码，然后用 IDEA 打开 `backend` 目录，启动 `QaApplication` 主类。后端默认端口 **8080**。

### 3. 启动前端

```bash
cd frontend
npm install
npm run dev
```

浏览器访问 `http://localhost:5173`。

> 详细步骤（含常见报错处理）见 `docs/部署指南.md`。
