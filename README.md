# 校园课程互助答疑系统

软件工程课程设计 —— 面向高校课程的问答互助平台

## 项目简介

本系统面向在校学生，提供按课程组织的问答互助功能。学生可针对具体课程发布疑问，其他同学跟帖解答，逐步沉淀为课程维度的知识库，解决课后答疑渠道分散、问题重复提问的问题。

系统采用前后端分离架构，包含学生端与管理员端两套完整业务：

- **学生端**：注册登录、按课程浏览与搜索帖子、发布问题（含图片）、回复评论、点赞收藏、个人中心管理
- **管理员端**：课程分类管理、帖子审核、用户管理、平台数据可视化统计

## 快速开始

### 1. 初始化数据库

```bash
mysql -uroot -p123456 --default-character-set=utf8mb4 -e "source ./docs/init.sql"
```

### 2. 启动后端（8080）

```bash
cd backend
mvn spring-boot:run
```

也可用 IDEA 打开 `backend` 目录，运行 `QaApplication`。启动前请确认 `backend/src/main/resources/application.yml` 中的数据库账号密码与本机一致。

### 3. 启动前端（5173）

```bash
cd frontend
npm install
npm run dev
```

浏览器访问 **http://localhost:5173**

> 详细步骤与常见报错处理见 `docs/部署指南.md`。
